# Sound slots

Drop a `.wav` file with one of these exact names into this folder, then reload the
game page. It plays automatically. You don't need to change any code. Slots
without a file stay silent.

| File name | When it plays | Status |
|---|---|---|
| `leaper-knee-break-1.wav` (`-2` optional variation) | A shot cuts off a piece of a Leaper leg | **Filled**: Freesound 423117 by ogsoundfx, "guns explosions album metal impact 5" |
| `gun-empty.wav` | Pulling the trigger with an empty magazine (both guns) | **Filled**: Freesound 154934 by klawykogut, "empty gun shot" |
| `lola-hurt-1.wav`, `lola-hurt-2.wav`, `lola-hurt-3.wav` | Lola is hit by a laser bolt (random variation) | Needed: short **female** pain grunt/inhale, not a scream |
| `lola-hurt-big.wav` | Lola is hit while at 20 HP or less | Needed: heavier female pain vocal |
| `lola-hit-thud.wav` | Under every Lola hit, beneath the voice | Optional: body/cloth impact thud |

Still to come: a separate sound for when a cut-off leg piece lands on the ground.
That needs its own slot, so ask for it to be connected once the file exists.

You can fill only some of the variations. The game picks from whichever files exist.
