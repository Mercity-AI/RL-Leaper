# Where the game's art came from

What is known about every non-sound asset the game ships, and what is not yet
known. Sounds are recorded one by one, with licences, in `src/audio/sounds.json`
(and listed in `CREDITS.md`). Items marked **Unknown** need an answer from the
owner before any public or commercial release; nothing here has been checked
beyond what the repository itself says.

## Lola (the player character)

- **Files shipped:** `assets/characters/lola/*.glb` (two outfits and twelve clip
  files), compressed into `assets/build/lola/` by `pnpm assets`. Textures inside
  them: `Arms_BaseColor`, `Boots_BaseColor`, `Head_BaseColor`, `Legs_BaseColor`,
  `Neck_BaseColor`, `Pants_BaseColor`, `Top_BaseColor`, `Lola_Gun_BaseColor`,
  `m416_base_color`.
- **Known:** exported by `scripts/export_lola.py` and `scripts/export_lola_clips.py`
  from the owner's Blender files `C:/Blender/LOWPOLY/Lola_both_animations.blend1.blend`,
  `C:/Blender/LOWPOLY/Lola_walk_final.blend` and `C:/Blender/LOWPOLY/Lola final.blend`
  (see `README.md`). The rigs are named `rig.001` and `Lola_M416_Rig`.
- **Unknown:**
  - Who modelled, textured and rigged Lola. Is she entirely the owner's own
    work, or built from a purchased or downloaded base mesh, generator or kit?
  - Where her animations came from: keyed by hand, motion capture, or a library
    such as Mixamo (its licence allows games but has its own terms).
  - Where the two gun models (the basic pistol and the M416) and their textures
    came from.
  - The Blender source files are not in the repository, so nobody else can
    rebuild or check them.

## The junkyard (the map)

- **Files shipped:** `assets/maps/junkyard/junkyard.glb` (compressed copy in
  `assets/build/maps/`), plus `collision.json`, `metrics.json` and `passages.json`
  made from it. Since 2026-10-19 its one texture is an atlas baked from the
  owner's procedural Blender materials (`scripts/bake_junkyard_textures.py`).
- **Known (since 2026-10-19):** the map is the owner's own yard,
  `Junkyard_Lola_walk_final_bus_textured.blend`, kept in the repository without
  its preview Lola as `assets/blockmesh/junkyard/junkyard_v2.blend` and, baked,
  `junkyard_v2_baked.blend`, which `scripts/export_junkyard.py` exports. It grew
  out of the first junkyard below, with the owner's containers, poles, spill
  piles and textured bus added.
- **Known (the first junkyard):** exported by `scripts/export_junkyard.py` from
  `assets/blockmesh/junkyard/junkyard_arranged.blend`, which is in the repository.
  Its props (tires, scrap heaps, cars, crane, containers, ...) are generated by the
  project's own Python scripts in `assets/blockmesh/junkyard/` and
  `assets/blockmesh/cars/` ("reproducible untextured junkyard props"). The layout
  ideas follow concept boards described in `docs/arena-concepts/`, which say they
  were drawn with an image-generation tool from the prompts recorded there.
- **Unknown:**
  - Whether anything in `junkyard_arranged.blend` other than the generated props
    came from elsewhere (it was arranged by hand in Blender).
  - The source of the "supplied junkyard concept" / "reference image" the prop
    notes mention, if it is not one of the generated concept boards.

## The Leaper (the enemy)

- **Known:** the robot is not a model file. It is built from simple shapes in
  code (`src/robot/createHexapod.js`), with materials and lights set there too.
  Its movement brain is the project's own trained network (`rl/frozen_7757824/`,
  `public/leaper.onnx`).
- **Unknown / to decide:** the names. "Leaper" and the page subtitle
  "ARC-CLASS HEXAPOD" follow the Leaper enemy of ARC Raiders (Embark Studios).
  The look and name are an homage; decide the public-facing names before a public
  release (review finding `ui-audio-no-attribution-or-provenance`, fix 5.18 step 6).

## Interface

- **Known:** icons (the gun silhouettes, the crosshair) are drawn in code as
  SVG or CSS; text uses the system's monospace font. No icon or font files ship.

## Code

- The game's own code has **no licence chosen yet** (owner decision). Third-party
  libraries and their licences are listed in `CREDITS.md`.
